# 傳奇十一人 XIFM

足球經理 × 抽卡網頁遊戲。抽真實現役同歷史球星唔同時期嘅卡，自由排兵佈陣，揀戰術，打聯賽。

- 純前端、單一檔案 `index.html`，無 build、無 server、無外部依賴（只用 Google Fonts）
- 直接用瀏覽器開，或者用 GitHub Pages：`https://fiveathree.github.io/XIFM/`
- 進度存喺瀏覽器 `localStorage`（key：`legendxi-v1`），換機或清瀏覽器資料會重新開始

## 玩法

| 頁面 | 內容 |
|---|---|
| 排兵佈陣 | 球場上撳位置揀人、拖卡自由擺位；8 個預設陣式 + 自訂；7 種戰術；7 個後備；3 個陣容方案；自動排最強（會避開受傷同攰嘅球員） |
| 抽卡 | 單抽 100 金幣、十連抽 900（保底 SR 或以上）；重複卡會留低 |
| 卡冊 | 按等級／位置／名稱篩選；撳卡睇六項能力同該球員所有時期版本；用重複卡升級或者賣卡 |
| 聯賽 · 盃賽 | 7 個聯賽、主客雙循環；8 個盃賽（歐聯 16 隊、其餘 8 隊），單場淘汰、打和射十二碼；3 個難度；友誼賽任揀對手 |

### 比賽

- 比賽逐分鐘進行，半場會停低畀你換人、改戰術；撳「換人 · 戰術」隨時暫停
- 每場最多換 5 人，換咗落場嘅球員唔可以再上
- 上場會消耗體力，體力低過 70 會扣分；冇上場嘅球員會回復，所以要輪換
- 球員有機會受傷，要休息一至三場

### 升級

重複卡可以用嚟升級張卡，最多 Lv5，每級評分同六項能力各 +1。升 Lv1 要 1 張重複，Lv2 要 2 張，如此類推，另外要金幣。唔想升級可以賣返做金幣。

卡池共 1308 張（UR 11 · SSR 144 · SR 397 · R 614 · C 142），包括 2025/26 球季版本同 2025 年夏天嘅轉會。

## 經理生涯 01/02（`fm.html`）

主頁右上角「經理生涯 01/02」入去。玩法似 2001 年嘅經典足球經理遊戲，獨立存檔，唔影響上面嘅卡冊同金幣。

- **五個開局球季**：1994/95、1998/99、2001/02、2004/05、2010/11，每個年代都係嗰季嘅真實球員同球隊（開新遊戲時揀）
- **13 個聯賽**：英格蘭四級、蘇超、西甲、意甲、德甲、法甲、荷甲、葡超、土超、比甲，加 18 隊歐洲球會；每個聯賽都有自己嘅盃賽
- **一日一日推進**：撳「下一日 ▶」；「⏩ 到比賽」會一直推到下場比賽、收到報價或者有工作邀請先停
- **比賽直播**：逐分鐘旁述同球場動畫，1×／2×／4× 速度；半場同加時會停低畀你換人（最多 3 個）、改陣式同打法；可以跳到完場
- **陣容**：撳一個球員再撳另一個就對調；每人可以設個人指令（盤扭、傳中、遠射等）
- **轉會同合約**：出價、還價、傾週薪同年期；3 月 28 日截止，7 月 1 日重開；可以放售、續約、解約
- **球探抽卡**：用球會資金抽全世界嘅球員，抽中即刻加盟；球探等級越高，抽中 SR 嘅機會越大
- **球會**：財政、票價、球場擴建、訓練、職員、董事局信心；成績差會被炒，之後可以接其他球會嘅工作邀請
- **賽事**：聯賽、英格蘭升降班同升級附加賽、足總盃、聯賽盃、各國盃賽、歐聯、歐洲足協盃；數據排名同歷史紀錄
- **存檔**：3 個存檔位，自動儲存；可以匯出／匯入去第二部機
- **秘技**：連撳左上角隊徽 5 下，`GOAT` 開／關無限資金，`SIUUU` +£100m

資料限制：2001/02 資料最齊（大約 3,700 個真實球員）；其他年代大球會齊，細會同英格蘭低級別球員偏少。唔夠 18 人嘅球隊會用標明「青年軍」嘅填充球員補上，水平按球會聲望。能力值係我哋自己估，唔係原版遊戲數字；盃賽冇重賽，歐聯一律用 32 隊分組，只有英格蘭有升降班。
