# 傳奇十一人 XIFM

足球經理抽卡網頁遊戲。

- 抽卡：真實現役及歷史球員，同一球員唔同時期係唔同卡，評分 50–105，共 914 張卡
- 等級：C (50–69) · R (70–79) · SR (80–89) · SSR (90–100) · UR (101+，歷史巔峰傳奇，每人一張)
- 排兵佈陣：8 個預設陣式，亦可以拖卡自創陣式；位置自動判斷，非本位扣分，同球會／同國籍有默契加成
- 聯賽：英超、西甲、意甲、德甲、法甲、國家隊大賽、傳奇盃，另有友誼賽
- 球員能力：每張卡有六項能力值（門將另有一套），喺卡冊撳卡睇
- 戰術：均衡、控球傳導、高位壓迫、快速反擊、邊路傳中、擺大巴、全力進攻，效果按球員能力計
- 比賽：簡單文字直播模擬

單一檔案 `index.html`，無需安裝，直接用瀏覽器開；進度存喺瀏覽器 localStorage。
