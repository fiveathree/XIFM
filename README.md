# 傳奇十一人 XIFM

足球經理 × 抽卡網頁遊戲。抽真實現役同歷史球星唔同時期嘅卡，自由排兵佈陣，揀戰術，打聯賽。

- 純前端、單一檔案 `index.html`，無 build、無 server、無外部依賴（只用 Google Fonts）
- 直接用瀏覽器開，或者用 GitHub Pages：`https://fiveathree.github.io/XIFM/`
- 進度存喺瀏覽器 `localStorage`（key：`legendxi-v1`），換機或清瀏覽器資料會重新開始

## 玩法

| 頁面 | 內容 |
|---|---|
| 排兵佈陣 | 球場上撳位置揀人、拖卡自由擺位；8 個預設陣式 + 自訂；7 種戰術；7 個後備；3 個陣容方案；自動排最強（會避開受傷同攰嘅球員） |
| 抽卡 | 單抽 100 金幣、十連抽 900（保底 SR 或以上）；重複卡會留低 |
| 卡冊 | 按等級／位置／名稱篩選；撳卡睇六項能力同該球員所有時期版本；用重複卡升級或者賣卡 |
| 聯賽 · 盃賽 | 7 個聯賽、主客雙循環；8 個盃賽（歐聯 16 隊、其餘 8 隊），單場淘汰、打和射十二碼；3 個難度；友誼賽任揀對手 |

### 比賽

- 比賽逐分鐘進行，半場會停低畀你換人、改戰術；撳「換人 · 戰術」隨時暫停
- 每場最多換 5 人，換咗落場嘅球員唔可以再上
- 上場會消耗體力，體力低過 70 會扣分；冇上場嘅球員會回復，所以要輪換
- 球員有機會受傷，要休息一至三場

### 升級

重複卡可以用嚟升級張卡，最多 Lv5，每級評分同六項能力各 +1。升 Lv1 要 1 張重複，Lv2 要 2 張，如此類推，另外要金幣。唔想升級可以賣返做金幣。

### 卡牌等級

| 等級 | 評分 | 抽中機率 |
|---|---|---|
| UR | 101+（歷史巔峰傳奇，每人只有一張） | 0.6% |
| SSR | 90–100 | 4% |
| SR | 80–89 | 14% |
| R | 70–79 | 33% |
| C | 50–69 | 48.4% |

卡池共 1308 張（UR 11 · SSR 144 · SR 397 · R 614 · C 142），包括 2025/26 球季版本同 2025 年夏天嘅轉會。

### 秘技

快速連撳左上角「傳奇XI」logo 5 下，輸入：

- `GOAT`：開／關無限金幣
- `SIUUU`：+100,000 金幣
